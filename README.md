## 🚀 INSTALLATION (Not Recommended)

### Prerequisites
- A sense of humor ✅
- Strong stomach ✅
- Love for terrible design ✅
- 800x600 monitor (optional but recommended)
- Windows XP nostalgia

### Steps

```bash
# Clone this masterpiece
git clone https://github.com/evilUrge/worst-site-ever.git

# Enter the nightmare
cd worst-site-ever

# Install dependencies (pray)
npm install

# Build the horror
npm run build

# Serve the abomination
npm run start

# Deploy to Cloudflare Pages (recommended subdomain: legendary.maoz.dev)
```
